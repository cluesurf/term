# Internationalization (i18n)

Seed provides a built-in i18n DSL for managing translations across
multiple locales. Define translation keys once per locale, use
interpolation and pluralization, and switch languages at runtime.

## Defining Translations

Use `seed i18n` with a locale code. Each `link` maps a key to a
translated string.

```tree
seed i18n, name en
  link add-placeholder, text <What needs doing?>
  link add-button, text <Add>
  link clear-done, text <Clear completed>
```

```tree
seed i18n, name es
  link add-placeholder, text <Que hay que hacer?>
  link add-button, text <Agregar>
  link clear-done, text <Borrar completados>
```

## Nested Translation Keys

Group related keys under a parent `link` block.

```tree
seed i18n, name en
  link filter
    link all, text <All>
    link active, text <Active>
    link done, text <Done>
  link error
    link not-found, text <Page not found>
    link forbidden, text <Access denied>
```

Nested keys resolve with dot paths. The key `filter.all` maps to
`text <All>` in the example above.

## String Interpolation

Use `{{variable}}` inside `text` values. Pass the variable when
calling `translate`.

```tree
seed i18n, name en
  link greeting, text <Hello, {{name}}!>
  link welcome, text <Welcome to {{app}}, {{name}}.>
```

```tree
call translate
  bind key, text <greeting>
  bind name, text <Lance>
```

This produces `Hello, Lance!`.

## Pluralization

Use `case` children to define plural forms. The runtime selects the
correct form based on the `count` value.

```tree
seed i18n, name en
  link count
    case zero, text <Nothing to do>
    case one, text <1 thing left>
    case other, text <{{count}} things left>
```

```tree
seed i18n, name es
  link count
    case zero, text <Nada que hacer>
    case one, text <1 cosa pendiente>
    case other, text <{{count}} cosas pendientes>
```

Pass the count when translating:

```tree
call translate
  bind key, text <count>
  bind count, mark 5
```

This produces `5 things left` in English or `5 cosas pendientes` in
Spanish.

Languages with more plural categories (such as Arabic or Polish) add
additional `case` entries like `case two`, `case few`, and `case many`.

## Multiple Locales

Define each locale in its own `seed i18n` block. All blocks can live
in the same file or in separate files per locale.

```tree
seed i18n, name en
  link add-placeholder, text <What needs doing?>
  link add-button, text <Add>
  link filter
    link all, text <All>
    link active, text <Active>
    link done, text <Done>
  link count
    case zero, text <Nothing to do>
    case one, text <1 thing left>
    case other, text <{{count}} things left>

seed i18n, name es
  link add-placeholder, text <Que hay que hacer?>
  link add-button, text <Agregar>
  link filter
    link all, text <Todos>
    link active, text <Activos>
    link done, text <Hechos>
  link count
    case zero, text <Nada que hacer>
    case one, text <1 cosa pendiente>
    case other, text <{{count}} cosas pendientes>

seed i18n, name fr
  link add-placeholder, text <Que faut-il faire?>
  link add-button, text <Ajouter>
  link filter
    link all, text <Tous>
    link active, text <Actifs>
    link done, text <Faits>
  link count
    case zero, text <Rien a faire>
    case one, text <1 chose restante>
    case other, text <{{count}} choses restantes>
```

## Using Translations in Components

Call `translate` with a `key` binding to insert translated text into
zones.

```tree
zone todo-header
  zone heading
    call translate
      bind key, text <add-button>

  zone input
    seed placeholder
      call translate
        bind key, text <add-placeholder>
```

For nested keys, use dot notation:

```tree
zone filter-bar
  zone tab
    call translate
      bind key, text <filter.all>
  zone tab
    call translate
      bind key, text <filter.active>
  zone tab
    call translate
      bind key, text <filter.done>
```

For pluralized keys, pass the count:

```tree
zone status
  call translate
    bind key, text <count>
    bind count, read remaining
```

## Dynamic Locale Switching

Store the active locale in app state and update it at runtime.

```tree
seed store, name app
  link locale, like text
    base text <en>

  task set-locale
    take locale, like text
    save self/locale, read locale
```

Switch the locale from a component:

```tree
zone locale-picker
  zone button
    seed click
      call app/set-locale
        bind locale, text <en>
    call translate
      bind key, text <lang.english>

  zone button
    seed click
      call app/set-locale
        bind locale, text <es>
    call translate
      bind key, text <lang.spanish>

  zone button
    seed click
      call app/set-locale
        bind locale, text <fr>
    call translate
      bind key, text <lang.french>
```

When `app/locale` changes, all `translate` calls re-evaluate with the
new locale.

## Date and Number Formatting

Use `call format-date` and `call format-number` to produce
locale-aware output.

```tree
zone order-summary
  zone date
    call format-date
      bind value, read order/created-at
      bind style, text <long>

  zone price
    call format-number
      bind value, read order/total
      bind style, text <currency>
      bind currency, text <USD>
```

The formatter uses the active locale from the store. In English this
might produce `March 9, 2026` and `$42.50`. In French it would produce
`9 mars 2026` and `42,50 $US`.

Available date styles: `short`, `medium`, `long`, `full`.

Available number styles: `decimal`, `currency`, `percent`.

## Fallback Locale

Define a fallback locale so missing keys resolve to a default
language instead of showing raw key names.

```tree
seed i18n
  link fallback, text <en>
```

When a key is missing from the active locale, the system looks it up
in the fallback locale. If the key is also missing from the fallback,
the missing translation handler runs.

## Missing Translation Handling

Configure what happens when a translation key is not found in any
locale.

```tree
seed i18n
  link fallback, text <en>
  link missing, text <key>
```

The `missing` option controls the output:

- `text <key>` displays the raw key name (default).
- `text <empty>` displays an empty string.
- `text <error>` raises a compile-time error if the key is statically
  known, or a runtime warning if dynamic.

During development, missing translations log a warning with the key
name and locale so they can be found and fixed.

## Feature Summary

| Feature | Syntax | Example |
|---|---|---|
| Declare locale | `seed i18n, name code` | `seed i18n, name en` |
| Simple key | `link key, text <value>` | `link add-button, text <Add>` |
| Nested keys | nested `link` blocks | `link filter` / `link all, text <All>` |
| Interpolation | `{{variable}}` in text | `text <Hello, {{name}}!>` |
| Pluralization | `case zero/one/other` | `case one, text <1 item>` |
| Look up translation | `call translate` | `bind key, text <greeting>` |
| Pass variables | `bind name, value` | `bind name, text <Lance>` |
| Active locale | `seed store` with locale link | `link locale, like text` |
| Switch locale | `call app/set-locale` | `bind locale, text <es>` |
| Format date | `call format-date` | `bind style, text <long>` |
| Format number | `call format-number` | `bind style, text <currency>` |
| Fallback locale | `seed i18n` + `link fallback` | `link fallback, text <en>` |
| Missing handling | `link missing` | `link missing, text <key>` |
